튜토리얼이다.플레이어는 기지 내부 코어실에서 시작해 기본 조작을 익히고, 외부 구역으로 진입하여 시간 감소와 전투를 경험한 뒤, 드랍 아이템을 획득하고 기지로 복귀한다.기지 복귀 후에는 설비 설치 구역으로 이동하여 생체 추출기를 설치하고, 전투에서 획득한 재료를 투입하여 의료용 겔을 출력한다. 이후 생체 주입기를 설치하고 의료용 겔을 투입하여 소형 나노 힐링 앰플을 제작한다.플레이어는 제작된 소형 나노 힐링 앰플을 사용하여 외부 구역 탐사 중 감소한 Time(HP/체력)을 회복한다. 이를 통해 전투 보상, 설비 가공, 전술 소모품 제작, 생존 자원 회복이 하나의 루프로 연결된다는 점을 학습한다.튜토리얼은 별도 안내자나 긴 설명문 없이 짧은 목표 문구를 통해 진행되며, 플레이어가 직접 행동하면서 게임의 기본 구조를 이해하도록 설계한다.현재 코드 기준으로 기본 진행은 이동, 키 입력, Trigger 도달, 적 처치까지 기존 Objective로 구성한다. 아이템 획득, 설비 설치, 재료 투입, 가공품 출력, 전술 소모품 사용, Time 회복 확인은 게임 시스템의 처리 완료 지점을 Quest 시스템으로 전달하는 ObjectiveSO 기반 신규 Objective와
