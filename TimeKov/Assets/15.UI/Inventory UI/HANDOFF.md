# TimeKov — 인벤토리 / 창고 UI 유니티 핸드오프

> **목적:** 화면을 못 보는 개발자가 이 문서만으로 UI를 100% 동일하게 재현한다.
> **원본:** HTML/CSS 프로토타입 (`Inventory UI.html` + `app.jsx` / `components.jsx` / `icons.jsx` / `data.jsx`). 모든 수치는 그 CSS에서 그대로 가져온 실측값이다.
> **저장 위치:** `Assets/11.UI/Inventory/` (이 .md) · 스프라이트는 `Assets/11.UI/Inventory/sprites/`. **Resources에 넣지 말 것**(인스펙터 직렬화 참조).

## 0. 먼저 읽을 것 — 데모 전용 요소 (옮기지 말 것)

프로토타입 화면에만 있는 **제작용 UI**다. 인게임에 구현하지 않는다:
- 상단 중앙 **"단독 가방 / 창고+가방" 토글** — 실제로는 **TAB = 단독 가방, F = 창고+가방** 키로 연다.
- 우상단 **"블러 26px" 슬라이더** — 블러 값을 실험하려고 둔 것. 최종 고정값은 §5에 명시.
- 좌상단 **"TIMEKOV" 워드마크** — 데모 라벨.
- 뒤 배경의 게임 스크린샷 — 실제로는 살아있는 게임 화면.

나머지 패널 내부 요소는 전부 실제 UI다.

## 0.5 ★ 최종 구조 (이 섹션이 최신 — 색은 §3 대신 여기 기준)

> 디자인은 엔드필드 톤(**밝은 간유리 + 어두운 슬롯 셀**)으로 확정됐다. 아래가 현재 프로토타입의 실제 구조이며, 색/블러는 **Unity(FlexibleBlur)에서 최종 조정**한다. 핵심은 "레이어를 어떻게 쌓고 블러를 어디에 거느냐"다.

### A. 패널 = 레이어 스택 (가장 중요)
뒤→앞 순서로 쌓는다:
```
[게임 월드]
  └ [베이스 패널]  어두운 톤 rgba(26,31,38,0.30) + 블러   ← 전체를 덮는 얇은 back layer
       (가장자리에 3px 얇게 + 푸터 영역에서 그대로 노출됨 = 그게 "검정 푸터")
      ├ [헤더 밴드]   밝은 간유리 rgba(214,219,224,0.60), 블러X, 아래 hairline   ← 가방 아이콘+타이틀 / X
      ├ [용량 밴드]   헤더와 동일 톤 (밝음)                                      ← "용량 19/35"
      ├ [그리드 밴드] 밝은 간유리 rgba(206,211,217,0.50) + 블러                  ← 스크롤되는 슬롯 영역
      └ [푸터]        bg 없음 → 베이스가 비침 (어두움)                           ← 정렬 버튼
```
- **밝은 밴드(헤더·용량·그리드)는 같은 톤**이라 하나로 이어져 보인다. 셋 사이엔 선/단차 없음.
- **푸터는 별도 검정이 아니라** 맨 뒤 베이스 레이어가 드러난 것. 가장자리 3px 테두리도 같은 베이스다.
- 헤더 아래에만 hairline 1줄 (`rgba(20,24,30,0.5)`).

### B. 블러를 어디에 거나
- **그리드 밴드**에만 backdrop blur(=FlexibleBlur)를 건다. 헤더·용량은 안 건다. (스크롤되는 아이템 영역만 뒤가 흐려짐)
- 단, 패널 자체가 투명 프레임이면 밴드별로 따로 걸어야 한다 → Unity에선 **베이스 패널 1장 블러 + 그리드 밴드 1장 블러**, 총 2개의 블러 영역으로 충분.

### C. ★ 색 보정 — 맵 색 입힘 방지 (반드시)
- 블러는 색을 지우지 못해 **맵 배경색이 패널에 입혀진다** (초록 맵→패널 초록빛, 황토 맵→누런빛).
- 해결: 블러에 **채도 낮추기(desaturate)**를 같이 건다. 프로토타입은 `saturate(0.5)`. → 맵이 뭐든 중립 회색 간유리로 보임.
- FlexibleBlur에 vibrancy/saturation 노브가 있으면 **0.4~0.6**으로. 없으면 블러 RT에 desaturate 패스 1개 추가.

### D. 슬롯 셀 (디자인 확정)
- 90×90, **각진 네모**(radius 2), 간격 14, 한 화면 **4행** 노출 + 세로 스크롤.
- 채움: 연한 검정 `rgba(26,30,36,0.30)` / 빈칸 `rgba(20,24,30,0.20)`.
- **테두리 = 진한 검정 2px** `rgba(10,12,16,0.55)`.
- 아이콘 한 변 60(=칸의 ~67%), 등급색 틴트.
- **등급 = 하단 언더라인 4px + 위로 번지는 오로라**(46px 높이, 등급색 `→투명` 그라데이션). 커먼=없음.
- 수량 = 우상단 검은 칩(흰 등폭 14px). NEW = 좌상단 빨강 점.

### E. 헤더 디테일
- 좌측: **가방 아이콘**(테두리 없는 단색 아이콘, PNG 교체 예정) + 타이틀 27px/700.
- 우측 끝: **SF 스타일 X** (글리프 네 끝에 코너 브래킷 팁, 박스 없음). 헤더는 위아래 여백 적게 **컴팩트**.
- **용량**: "용량 19/35"(붙여서), 22~24px. 가방→용량 간격 좁게, 용량→그리드 간격 넓게.

### F. 간격
- 단독 가방 한 화면 4행, 패널 세로 컴팩트.

- **기준 해상도 1920 × 1080 (16:9).** 모든 px 값은 이 기준.

## 4. ★ 레이어 깊이 구조 (엔드필드 "간유리" 느낌의 핵심)

평평하면 절대 그 느낌이 안 난다. **3단 깊이**로 쌓는다 (뒤→앞):

```
[게임 월드 (실제 3D 화면)]
  └ [패널 본체]  rgba ~0.55 알파 + backdrop blur 26px   ← 뒤가 흐릿하게 비침
      ├ [헤더 바 / 푸터 바]  rgba ~0.50 알파 + blur 22px  ← 더 불투명, "떠 있는 바"
      ├ [본문 톤 판]  창고=어둡게 / 가방=밝게 (얇은 알파)   ← 두 패널 구분
      │   └ [슬롯 타일]  rgba ~0.16 알파 + 자체 blur 26px  ← 칸마다 frosted, 뒤가 비침
      │       ├ 아이템 아이콘(등급색) / 수량칩 / NEW점 / 등급바
      │       └ 테두리 + 외부그림자(0 3px 10px rgba(0,0,0,0.26)) + 상단 하이라이트(inset 0 1px 0 rgba(255,255,255,0.13))
```

핵심 규칙:
1. **헤더·푸터 바가 본문보다 더 불투명**해서 바가 떠 보인다.
2. **본문(슬롯 사이 여백)은 투명**해서 게임 화면이 블러로 비친다.
3. **슬롯 칸은 각자 frosted glass**(반투명 + 블러)라 칸 안에 뒤가 흐릿하게 비친다 → §9-A 구현법.
4. **창고 본문은 어둡게, 가방 본문은 밝게** 깔아 두 패널을 시각적으로 분리.

## 5. 블러 값 (고정)

| 대상 | backdrop blur | 비고 |
|---|---|---|
| 패널 본체 | **26px** | saturate 1.15 |
| 슬롯 타일 | **26px** | saturate 1.22 |
| 헤더/푸터 바 | **22px** | saturate 1.10 |

> 프로토타입 슬라이더는 8~40px 실험용. **최종은 위 고정값.** (CSS `backdrop-filter: blur(26px)`.)

## 9. ★★ 효과 / 애니메이션 (전부)

> CSS 원값을 그대로 적는다. Unity는 DOTween 등으로 동일 타이밍·이징 매핑.

### 9-A. 슬롯 frosted 블러 (가장 중요 — 구현 난관)
- **현상:** 각 슬롯 칸 안에 그 칸 위치의 게임 화면이 **블러 26px**로 흐릿하게 비친다(반투명 알파 0.14~0.18).
- **CSS:** `backdrop-filter: blur(26px) saturate(1.22)` + 위 슬롯 배경 알파.
- **Unity UGUI엔 요소별 backdrop blur가 없음.** 두 가지 길:
  - **(A·권장) 패널 전체 블러 1장 + 슬롯 반투명 틴트.** FlexibleBlur로 패널 뒤 영역을 한 번 블러한 RenderTexture를 만들고, 패널·슬롯은 그 위에 §3-3 알파 틴트만 얹는다. 슬롯 칸도 같은 블러 텍스처를 배경으로 쓰되 알파만 다르게. → 결과는 칸마다 블러된 것과 사실상 동일.
  - **(B) 슬롯별 마스크 샘플링.** 블러 RT를 각 슬롯 RectMask로 샘플 — 정확하지만 무겁다. 권장 안 함.
- **반드시 (A)로.** 패널·슬롯을 불투명하게 칠하면 절대 안 됨(중앙 투명 유지, 블러가 비치게).

### 9-B. 패널 열기 (인트로)
- **순서:** 블러 패널 먼저 깔린 뒤 내용물 페이드인. **접힘(fold) 아님.**
- 패널 본체: `opacity 0→1` + `scale 0.984→1` + `translateY 8px→0`, **0.34s**, ease `cubic-bezier(0.2,0.7,0.2,1)`.
- 내용물(헤더/카테고리/그리드/하단바): `opacity 0→1`, **0.55s ease**, **delay 0.16s**.
- 닫기 버튼: `opacity 0→1`, 0.5s, delay 0.22s.
- (스태거를 더 주고 싶으면 슬롯을 좌→우 40ms 간격으로 페이드인해도 좋음 — 원본은 통째 페이드.)

### 9-C. 슬롯 호버
- 테두리 → 시안, `transform: translateY(0→−1px)`, 글로우 `box-shadow 0 0 16px rgba(95,196,255,0.32)`.
- **0.13s ease** (box-shadow·border·transform 동시).

### 9-D. 슬롯 선택
- 테두리 → 밝은시안, 글로우 `0 0 26px rgba(95,196,255,0.51)` **상시 유지**, 아이콘 `drop-shadow 0 0 6px 등급색`.
- 0.13s ease. (선택 호흡 펄스는 원본에 **없음**. 원하면 글로우 alpha 0.5↔0.8, 1.4s ease-in-out 무한 권장.)

### 9-E. NEW 점
- 슬롯 좌상단 10px 원, `#aee3ff` + 글로우 `0 0 8px #5fc4ff`.
- 원본은 **정적**(펄스 없음). 펄스 원하면 `scale 1↔1.25 + opacity 1↔0.6, 1.2s ease-in-out 무한`.

### 9-F. 정리(자동정렬)
- 정렬을 "분류순"으로 바꾸고 NEW 표시 해제 + 토스트("정리 완료 — 분류순으로 자동 정렬").
- 슬롯 재배치는 즉시(원본). 부드럽게 하려면 위치 이동 0.2s ease-out 권장.

### 9-G. 일괄보관 / 일괄가져오기
- 해당 필터의 아이템을 반대 패널로 이동, 동일 아이템 수량 합산, 공간 초과분은 남김. + 토스트("N종 창고로 보관").
- 원본은 **즉시 이동**(날아가는 연출 없음). 연출 추가 시: 아이템 아이콘이 대상 패널 중심으로 `position 이동 + scale 1→0.6 + opacity 1→0`, 0.3s ease-in, 50ms 스태거 권장.

### 9-H. 토스트
- 하단 중앙, 배경 `rgba(12,22,36,0.92)` + blur 8, 좌측 3px 시안 막대.
- 등장 `opacity 0→1 + translateY 12px→0`, **0.25s**. **1.7s 후** 반대로 사라짐.

### 9-I. 탭(카테고리) 전환
- 필터만 바뀜. 선택 탭 배경/테두리/아이콘색 전환 0.14s ease. 슬롯 목록 즉시 갱신.

### 9-J. 레이아웃 전환(TAB↔F)
- 패널 교체 시 §9-B 인트로 재생(타이머 480ms 바운드).
