# 코어 강화 UI — 구현 스펙 / Handoff

> ## ⛔ 먼저 읽기 (가장 중요)
> - **이 폴더의 `app.jsx` / `styles.css`가 유일한 정답(Source of Truth)이다.**
>   기억·상상·일반적인 "강화 UI 관습"으로 새로 만들지 말 것. **반드시 파일을 그대로 읽어 옮길 것.**
> - **스탯은 "체력"(=시간) 하나뿐이다.** ❌ 스태미나/Stamina, ❌ 공격력/ATK, ❌ 방어력/DEF,
>   ❌ 기타 어떤 능력치도 **추가 금지.** 화면에 표시되는 수치는 오직 **체력(초, s)**.
> - 강화 = **시계 타이밍 미니게임**(코어→시계→정지 판정→코어). 단순 "확률 강화 버튼"으로 축소 금지.
> - 화면 구성은 아래 [최종 화면]과 100% 일치해야 한다. 항목을 임의로 더하거나 빼지 말 것.
>

게임 "TimeKov"의 코어 강화 화면. 핵심 컨셉: **시간 = 체력**.
코어를 강화하면 체력(시간)이 +30s씩 증가. 강화는 **스타포스식 타이밍 미니게임**으로 성공 확률을 올린다.

이 폴더는 **목업/스펙(reference)**입니다. 브라우저로 `코어강화UI.html`을 열면 모든 인터랙션이
실제로 동작합니다(React/Babel은 CDN 로드 → 인터넷 필요). Unity(uGUI) 등 실제 스택에는
아래 로직/수치/연출을 그대로 옮겨 구현하세요.

## 파일 구성

- `app.jsx` — 상태/로직/렌더 전체(미니게임 핵심)
- `styles.css` — 비주얼(블루 sci-fi, 게이지, 시계)
- `core.png` — 코어 실물 이미지(투명배경, 실제 게임 에셋)
- `tweaks-panel.jsx` — 디자인 튜닝 패널(프로토타입 전용, 이식 시 불필요)
- `reference/` — **원본 게임 코어 UI 에셋(참고용, 구현 대상 아님)**. 우리 화면은 이 톤을
  재해석한 것. 그대로 베끼지 말고 분위기 참고만. 실제 정답 화면은 위 [최종 화면] / `app.jsx`.

  - `StatPanel.png` 스탯 패널 · `MaterialPanel.png` 재료 패널 · `ItemSlot.png` 아이템 슬롯

## 핵심 인터랙션: 코어 → 시계 → 코어
1. 강화 시작 → 코어가 시계로 크로스페이드 변신, 바늘 회전 시작
2. 시계판 상단에 성공존(초록 아크) + 퍼펙트존(골드 아크)
3. 정지!(클릭/Space) → 바늘 정지 위치로 판정
   - PERFECT(퍼펙트존): +perfectBonus%
   - GOOD(성공존): +goodBonus% × 근접도(가장자리일수록 감소, 0.4~1.0)
   - MISS(존 밖/미정지): +0%
4. 판정 칩(PERFECT/GOOD/MISS +N%) + 게이지에 보너스 구간(초록) 연장
5. 최종 확률 = 기본확률 + 보너스(0~100 클램프)로 성공 굴림
6. 성공 → 레벨+1, 체력 +30s / 실패 → 변동 없음
7. 시계 → 코어 복귀(idle)

## 상태 머신 (phase)
idle → spin → judge → result → idle
- idle: 코어 표시, "강화 시작" 활성(키트 충분 & 레벨<10)
- spin: 시계+회전 바늘, "정지!", Space 정지, 6초 미정지 시 자동 MISS
- judge: 정지·판정 칩·게이지 보너스(약 1.1s)
- result: 성공/실패 배너(약 1.6s) → idle

## 튜닝 수치 (app.jsx 상단 TWEAK_DEFAULTS + 파생식)
- rate: 기본 성공률 % (기본 50)
- difficulty: 난이도 1~4 (기본 2) → 바늘 빠름·존 좁아짐
- perfectBonus: 퍼펙트 보너스 % (기본 45)
- goodBonus: 성공존 보너스 % 최대 (기본 22)
- haveKits: 코어 키트 보유 수 (기본 3) / needKits: 필요 수 (상수 3)
- period = 1400 - (difficulty-1)*220   바늘 1회전 ms
- zoneHalf = 30 - (difficulty-1)*4     성공존 반각(deg)
- perfectHalf = 10 - (difficulty-1)*1.2  퍼펙트존 반각(deg)
- TIME_BASE=100, TIME_STEP=30 → 현재=100+level*30, 강화후=현재+30
- 바늘 각도 상단(12시)=0도. 정지 시 절대각도로 거리 산출 → 존 판정.

## 구현 시 주의
- 상태 전환 opacity는 inline style로 제어(.clock/.tchip/.result). 이식 환경에선 일반 클래스 토글로 바꿔도 무방.
- 회전 바늘은 requestAnimationFrame으로 매 프레임 transform rotate 직접 갱신(ref). Unity면 코루틴/Update.
- tweaks-panel.jsx와 EDITMODE 마커는 프로토타입 튜닝용 → 이식 시 제거 가능.
- backdrop blur 미사용(uGUI 제약) — 깊이감은 반투명+시안 글로우로만.
- core.png는 실제 코어. 시계는 SVG로 그려짐(이식 시 동일 룩 스프라이트/메시로 대체 가능).
