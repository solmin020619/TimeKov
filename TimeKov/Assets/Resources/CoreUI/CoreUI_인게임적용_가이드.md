# 코어 강화 UI — 인게임 적용 가이드 (개정판)

> 처음 요청서 대비 **바뀐 핵심**: 코어가 "정지 PNG 1장"에서
> **① 코어 발광 PNG + ② 전류(파지직) 스프라이트 애니메이션** 으로 분리됨.
> 정지 이미지로는 지글거리는 연출이 안 나와서, 전류는 프레임 애니로 처리한다.
> 링 2장은 기존과 동일하게 코드로 Z회전.

---

## 1. 파일 목록 (`Resources/CoreUI/sprites/`)

| 파일 | 용도 | 크기 | 배경 | 블렌드 |
|---|---|---|---|---|
| `CoreOrb_glow.png` | 가운데 발광 코어(에너지 구). 정지. 코드로 펄스(맥동) | 512² | 투명 | **Additive(가산)** |
| `CoreCrackle_sheet.png` | 전류 스프라이트 시트. **4×4 = 16프레임**, 셀 512² | 2048² | 투명 | **Additive(가산)** |
| `CoreCrackle/CoreCrackle_00~15.png` | 위 시트의 개별 프레임 16장(원하는 방식 선택) | 512² | 투명 | **Additive(가산)** |
| `CoreRingA.png` | 짐벌 링 1 (큰 외곽, 한 축 기울기) | 768² | 투명 | 일반(알파) |
| `CoreRingB.png` | 짐벌 링 2 (다른 축 기울기) | 768² | 투명 | 일반(알파) |

- **모든 PNG는 도형 중심이 캔버스 정중앙**이다. 피벗/앵커를 **(0.5, 0.5)** 로 두면 회전·정렬이 안 흔들린다.
- 텍스처 임포트: **Compression = None(또는 고품질)**, Alpha Is Transparency = ✓, Wrap = Clamp.

---

## 2. 레이어 구성 (뒤 → 앞)

모두 **같은 정사각 위치에 중앙 정렬**, 동일 배율로 스케일.

```
(뒤)  CoreOrb_glow      ← 발광 코어 (펄스)
      CoreCrackle       ← 전류 애니 (Additive)
      CoreRingA         ← 회전 CW
(앞)  CoreRingB         ← 회전 CCW
```

- 발광/전류는 **같은 크기 사각**에 겹쳐 놓으면 정확히 맞물리도록 비율을 맞춰 뒀다(전류가 코어 발광보다 살짝 더 바깥까지 뻗음).
- 링은 코어보다 큰 사각이지만 **중심만 맞추면** 됨. (링 PNG는 768², 코어계열은 512² — 같은 화면 사각에 중앙 배치 후 균일 스케일.)
- 더 입체적으로 하고 싶으면 링 하나를 코어 앞/뒤로 나눠 배치(앞면 반만 위에 덧대기)해도 됨. 기본은 위 순서로 충분.

---

## 3. 애니메이션 파라미터 (프리뷰와 동일)

- **링A**: Z축 시계방향, 한 바퀴 ≈ **14초** (≈ 25.7°/s)
- **링B**: Z축 반시계방향, 한 바퀴 ≈ **9초** (≈ 40°/s)  ← 둘이 다른 속도라 자이로 느낌
- **전류(CoreCrackle)**: 16프레임 루프, **≈ 12~15 fps**.
  - 시작 프레임을 랜덤으로, 또는 매 루프 살짝 속도 흔들면 더 자연스러움.
  - 프레임이 서로 독립(랜덤)이라 빠르게 갈아끼우면 "지글지글 파지직"이 됨.
- **코어 펄스(CoreOrb_glow)**: scale 1.00 ↔ 1.06, alpha 0.9 ↔ 1.0, 주기 ≈ **3초** sin 왕복.

### 색
- 메인 시안 발광 `#5FC4FF` 계열 + 흰 핫코어.
- 전류는 시안 + **보라(약 30%, `#B08AFF` 계열) 섞임** — 자세히 보면 보라 아크가 보이도록.

## 4. Unity 적용 (둘 중 택1)

**A. 개별 프레임 (가장 확실)**
- `CoreCrackle_00~15.png` 16장을 Sprite로 임포트 → UI `Image`(또는 `SpriteRenderer`)에 코드로 매 프레임 인덱스 교체, 또는 Animator/Animation 클립으로 12~15fps 루프.
- Material/Shader는 **가산(Additive)** (예: UI/Additive, Particles/Additive).

**B. 스프라이트 시트**
- `CoreCrackle_sheet.png`를 Sprite Mode = Multiple → Sprite Editor에서 **Grid By Cell Count 4×4**로 슬라이스 → 16 스프라이트 애니.
- 또는 플립북 셰이더에 4×4로 먹임.

### 코드 연결 (참고 — 기존 요청서 구조)
- `CoreUpgradeUIBuilder`: 기존 CoreImage 자리에 **glow + crackle + ringA + ringB** 4레이어를 동일 중심으로 배치.
- `CoreUpgradeUI`: 링 회전 코루틴 2개(각각 다른 speed) + 전류 프레임 스왑 코루틴 + 코어 펄스 코루틴.
