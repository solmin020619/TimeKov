# 인벤토리 / 창고 UI — 정답 스펙

> sci-fi 미니멀 · 어두운 네이비 간유리 + 시안 포인트. 이 폴더의 `Inventory UI.html`은 작동하는 인터랙티브 목업이며, 아래는 PNG 에셋/구현 기준이 되는 스펙입니다.

## 0. 파일
| 파일 | 역할 |
|---|---|
| `Inventory UI.html` | 메인 — 스케일링 스테이지 + 스크립트 로더 + 전체 CSS |
| `icons.jsx` | 카테고리 7종 · 기능 아이콘 · 아이템 픽토그램 (라인아트 SVG) |
| `data.jsx` | 디자인 토큰 · 카테고리 · 등급 · 정렬 · 샘플 아이템 |
| `components.jsx` | 슬롯 · 등급바 · 툴팁 · 게이지 · 정렬 드롭다운 · 패널 프레임 |
| `app.jsx` | 상태 · 레이아웃 전환 · 필터/정렬/일괄이동 · 오프닝 페이드 · Tweaks |

## 1. 팔레트
| 토큰 | 값 |
|---|---|
| 베이스 네이비 | `#0e1a2c` ~ `#0b1422` (배경 그라데이션 `#12233a → #081019`) |
| 시안 포인트 | `#5fc4ff` / 밝은 시안 `#aee3ff` |
| 슬롯 | 면 `#16263c` / 테두리 `#34516f` |
| 텍스트 | 주 `#eaf3fb` / 보조 `#aebfd0` |
| 등급 | 커먼 = 없음(투명) · 어드밴스드 `#4f9be0` · 레어 `#34c06a` · 히어로 `#a64fe0` · 레전드 `#ffb020` |

> 블러는 런타임 처리. 패널 배경은 불투명하게 깔지 않음 — 중앙은 반투명 네이비, 시안 1px 테두리 + 코너 브래킷 데코만.

## 2. 규격
- 캔버스 **1920×1080** (16:9), 화면 비율에 맞춰 letterbox 스케일.
- 슬롯 **64×64px**, 간격 **9px**, 라운드 8px.
- 가방 **35칸**(7열×5행) · 창고 **50칸**(10열×5행).
- 패널 패딩 24/26px, 라운드 11px.
- 등급바 = 슬롯 **하단 언더라인**(좌우 9px 인셋, 높이 3px) — 풀 테두리 아님.
- 수량 = 슬롯 **우상단**(작은 frosted 칩, 등급바/아트와 겹치지 않음).
- NEW = 슬롯 좌상단 시안 점 + 발광.

## 3. 레이아웃
- **A. 단독 가방** (TAB): 단일 패널 / 헤더(가방 + 용량 N/35 게이지) / 카테고리 7행 / 슬롯 그리드 / 하단바(정렬 드롭다운·오름내림·정리·휴지통·일괄보관).
- **B. 창고 + 가방 듀얼** (F): 좌 창고(50칸, 하단 정렬·정리·휴지통) / 가운데 세로 시안 구분선 / 우 가방(35칸, 하단 일괄보관·일괄가져오기) / 우상단 공통 X.

## 4. 카테고리 7종 (1차·2차 구분 핵심)
| 키 | 라벨 | 아이콘 모티프 |
|---|---|---|
| all | 전체 | 3×3 점 그리드 |
| raw | 원재료 | 거친 결정/원석 (다면체) |
| primary | **1차 가공** | **주괴/판재 — 적층 금속 막대** |
| secondary | **2차 가공** | **정밀부품/회로 — 핀 달린 칩** |
| tactical | 전술 소비 | 메디키트 십자 |
| core | 코어 강화 | 육각 코어 |
| special | 특수 | 스파클 |

## 5. 인터랙션 (구현됨)
- 슬롯 호버/선택 발광 (스타일·강도 Tweaks).
- 카테고리 필터 (패널별 독립).
- 정렬 드롭다운(획득/이름/등급/수량/분류순) + 오름·내림 토글.
- 정리(분류순 자동 정렬 + NEW 해제).
- 휴지통(선택 아이템 삭제).
- 일괄보관(가방→창고) / 일괄가져오기(창고→가방) — 동일 아이템 수량 병합 + 용량 초과 시 보호.
- 키보드 **TAB**=단독 가방 · **F**=창고+가방 · **Esc**=선택 해제.
- 오프닝: 패널 먼저 깔린 뒤 내용물 alpha 0→1 페이드 (fold 아님, 타이머 바운드라 정지 화면에서도 보임).

## 6. Tweaks (툴바에서 토글)
등급바 표현(언더라인/코너/풀테두리) · 슬롯 발광(소프트/링/엣지) · 발광 강도 · 패널 블러 · 시안 포인트 색.

## 7. PNG 제작 시 주의
- 임포트 **Uncompressed** (DXT 압축이 얇은 선/그라데이션을 뭉개 "블러"처럼 보이는 사고 방지).
- 산출 위치: `Assets/11.UI/Inventory/sprites` (+ 본 README). **Resources에 넣지 말 것** — 인벤 패널은 인스펙터 직렬화 참조.
